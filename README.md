# Lista de Tarefas

Aplicação simples de lista de tarefas (to-do list) feita com HTML, JavaScript e
Bootstrap. Permite adicionar, editar, concluir e excluir tarefas, com os itens
sendo renderizados dinamicamente no navegador.

## Funcionalidades

- Adicionar tarefas pela descrição no campo de texto.
- Editar a descrição de uma tarefa existente.
- Marcar a tarefa como concluída (botão fica verde quando ativo e cinza quando
  pendente, com o texto riscado).
- Excluir tarefas individualmente.

## Tecnologias

- **HTML5** — estrutura da página (`index.html`).
- **JavaScript (ES6+)** — toda a lógica de manipulação do DOM em `main.js`,
  sem framework e sem etapa de build.
- **Bootstrap 5.3** — layout e componentes (input group, botões), carregado via
  CDN.
- **Bootstrap Icons** — ícones usados nos botões e no cabeçalho, carregados via
  CDN.
